# Favorite CMS Universal 1.2.1

Licenses & connection now separates Plugins, Themes and CMS & connection. Installed extensions use compact expandable rows with search, active/version labels and readable license states. License activation, checkout, deactivation and signed updates remain behind password and CSRF checks. Theme updates are labeled and submitted as theme updates. The CMS tab contains connection/refresh/transfer, site-user management and CMS updates; private installation policy controls link to Central Control only for the bound Owner.

Install through CMS Admin → Updates using Favorite-CMS-Universal-v1.2.1.zip. Server & License 1.0.0 is unchanged and does not need re-extraction. Content, users, settings, payments, keys and memberships are not migrated by this layout change. Existing CMS versions/release assets remain available; no historical ZIP is replaced.

Validation: disconnected/connected rendering, category separation, search, default theme, retained update/activation actions, CSRF and password denial; 18 category/theme/viewport layouts (1440, 390 and 320px) and 12 native details interactions. Screenshots use the actual rendered page inside an isolated appearance wrapper, not the live hosting site. Client protocol/licensing regressions and ZIP validation are checked separately. No live hosting deployment or paid/provider operation performed.
