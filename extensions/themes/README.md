# Themes repository catalog

Upload one complete extension ZIP per file here on main. Use a permanent lowercase ID and semantic version in theme.json at the ZIP root or inside one enclosing folder. Plugin packages require their normal entry point; themes require index.php. Do not include credentials, runtime storage or databases. Keep releases immutable: different bytes need a new extension version. These ZIPs are distribution artifacts, excluded from the public CMS installer.

Favorite Server and License → Repository catalog automatically checks main when opened (15-minute cache), or use Refresh catalog. Validate & import the package, then open Trial, price & policy. Existing legacy packages start Free. The Owner chooses Free, Trial + Paid or Paid and configurable price/term/activation/update packages. Refresh and later releases preserve those policies and previous purchases. Removing a source ZIP does not remove installed copies or existing license records.

Public repository ZIPs are publicly downloadable. For paid-source confidentiality use a private CMS repository and a read-only Contents token in Server → Repository catalog → Private repository access. The protected server signs imported releases and enforces download entitlements; a public source archive itself cannot be made private by licensing.
