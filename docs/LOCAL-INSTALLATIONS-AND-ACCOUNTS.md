
## নতুন Local installation ও Account directory
- localhost, *.localhost, *.local, *.test, private LAN IPv4 এবং IPv6 loopback/ULA URL-এ থাকা installation এখন outbound HTTPS দিয়ে official Server-এ register হয়। দুইটি computer/root-এ একই localhost URL হলেও আলাদা UUID + private installation key থাকে। Local নাম দিয়ে public domain ownership claim করা যায় না; central কখনো localhost/private URL fetch করে না। Dashboard-এ Local · outbound identity এবং প্রকৃত local URL দেখাবে। এটি public-domain verification বা hardware attestation নয়।
- Internet/central connection না থাকলে প্রথম local install pending অবস্থায় চলে। Internet ফিরলে পরের request/retry-এ register হয়। Registered local site-এ Owner Suspend/Ban/Reactivate signed policy অনুযায়ী কার্যকর হয়; outage-এ শেষ state থাকে। Local site সরিয়ে ফেলার অবস্থা বাইরে থেকে নিশ্চিত করা যায় না; তাই inbound monitoring দিয়ে local record auto-delete/archive করা হয় না। Owner manual retirement আছে।
- একই root/machine-এ local URL বা port বদলালে key ও UUID অক্ষত রেখে local binding update হয়।
- Local site পরে public HTTPS URL-এ গেলে, সংযুক্ত identity দিয়ে automatic ownership-verified transfer হয়। ID এবং license identity বজায় থাকে। অন্য root/machine-এ কপি করলে নতুন local identity হয়; copied runtime key থেকে public ownership অনুমোদন করা হয় না।
- Central Control → CMS sites & access → Accounts অথবা Details → Accounts & customer directory-তে site অনুযায়ী account ID, name, username, email, roles ও status দেখা যাবে। Account editing সংশ্লিষ্ট site-এর authenticated Users panel-এ থাকবে; এই release remote customer-account suspend/delete যোগ করেনি। Site-level control আগের মতো আছে।
- Account directory authenticated status request-এ সর্বোচ্চ ৫০টি করে sync হয়। Full cycle-এর পর ৫ মিনিট বিরতি; তারপর পরবর্তী cycle। Signed acknowledgement ছাড়া cursor এগোয় না। শেষ complete snapshot না আসা পর্যন্ত unseen account মুছে না। Source-এ deleted account পরের সম্পূর্ণ snapshot-এ তালিকা থেকে যায়। Last full sync, reported total ও sync pending/progress স্পষ্টভাবে দেখায়; offline হলে status পুরোনো হতে পারে। Password/hash/token, private content, payment secret, personal messages পাঠায় না। Installer ও administrator connection-recovery page-এ disclosure আছে; existing customers-কে update-এর সঙ্গে এই পরিবর্তন জানান।
- All Records ও প্রতিটি page মিলিয়ে সব নিবন্ধিত identity দেখা যায়। সমসময় register হওয়া row-এর pagination স্থির করতে ID-সহ ordering আছে। Registration issues-এ Server-এ পৌঁছানো failed verification-এর history থাকবে; সেগুলো approved site নয়। কখনো Server-এ পৌঁছায়নি এমন installation বা Internet-বিহীন machine Server নিজে আবিষ্কার করতে পারে না।
- Version অপরিবর্তিত (CMS 1.2.1, Server 1.0.1); repair build 2026112606। Existing settings storage-এ account প্রতি bounded metadata row ব্যবহার হয়েছে; destructive schema migration নেই। Backup ও Owner authority setup আগের নিয়মে। প্রথমে Server ZIP, তারপর CMS ZIP দিন। আগের valid authority certificate ও offline publisher backup/recovery key চলবে।
